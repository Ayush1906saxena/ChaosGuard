Completeness levels:
- complete: The fix fully addresses the vulnerability with no remaining risk
- partial: The fix reduces risk but leaves some attack surface or edge cases
- insufficient: The fix does not adequately address the vulnerability

Confidence scoring:
- 90-100: Very confident in the assessment, clear-cut case
- 70-89: Confident but some aspects require runtime verification
- 50-69: Moderate confidence, contextual factors could change the assessment
- Below 50: Low confidence, manual review strongly recommended

Common issues to check for:

- Fix uses a denylist instead of an allowlist

- Fix introduces a race condition or deadlock
- Fix breaks backward compatibility unnecessarily
